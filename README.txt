MEU CONTROLE FINANCEIRO (versão com Supabase)

Como usar:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html no navegador do celular ou computador (precisa de internet).
3. Crie uma conta com e-mail e senha (se o projeto exigir, confirme o e-mail) e entre.
4. Se houver lançamentos antigos salvos neste navegador, o app oferece importá-los para a sua conta.
5. Toque em "Novo lançamento", escolha Entrada ou Gasto e preencha os dados.

Onde os dados ficam:
- Projeto Supabase "Financas" (tabelas transactions e monthly_settings).
- Cada conta só enxerga os próprios dados (Row Level Security).
- Os dados acompanham a conta: dá para entrar de outro aparelho e ver tudo igual.

Recursos incluídos:
- Registro e edição de entradas e gastos.
- Saldo acumulado: o que sobrar (ou faltar) é levado automaticamente para o mês seguinte.
- Gastos no crédito ficam como "cartão pendente" e não reduzem o saldo até o pagamento da fatura.
- Campo para informar e editar gastos que já estavam na fatura ao começar o mês.
- Área própria para visualizar as entradas do mês.
- Categorias, datas e formas de pagamento/recebimento.
- Botão rápido "Gasto no cartão" e filtro "Só gastos no cartão".
- Filtro por mês, busca, tipo e categoria.
- Orçamento mensal para acompanhar os gastos.
- Visão dos gastos por categoria.
- Exportação do mês em CSV.
- Layout adaptado para celular.
