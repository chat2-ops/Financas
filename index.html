AUTOMAÇÃO

Compras da Carteira da Apple

Configure um token para o app Atalhos registrar compras por aproximação nos seus gastos.

Copie e guarde este token agora. Ele é mostrado uma única vez; se perder, gere outro para substituir.

Como configurar no app Atalhos
  1. No Atalhos, crie uma automação pessoal do tipo Transação e selecione o cartão da Carteira.
  2. Use os dados da transação como valor, estabelecimento e data; gere um UUID para p_request_id.
  3. Adicione “Obter Conteúdo do URL”: método POST, com o endereço e cabeçalhos indicados no arquivo LEIA-ME do pacote.

O app registra como “Crédito Apple Pay”, categoria “Outros”. Não compartilhe o token. O Atalho depende dos dados que o iPhone disponibilizar para aquela transação.
